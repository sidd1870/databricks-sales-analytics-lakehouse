
# Databricks Sales Analytics Lakehouse

## Project Overview

This project analyzes sales data using **Databricks SQL and Lakehouse architecture** to extract meaningful business insights.
It simulates a real-world analytics workflow followed by data analysts in modern companies.
Dataset: Retail orders dataset queried using Databricks SQL (~$29M total sales).

---

## Tools Used

* Databricks
* Databricks SQL
* Delta Lake
* Databricks Dashboards
* Databricks AI Genie
* GitHub

---

## Dataset

The dataset consists of structured sales data stored in Databricks.

Tables used:

* `dim_customers` – customer details (country, age, etc.)
* `dim_products` – product hierarchy (category, subcategory, product)
* `fact_sales` – sales transactions (sales, quantity, profit, date)

---

## Tasks Performed

* Data exploration using Databricks SQL Editor
* Table inspection and schema analysis
* Sales and customer metrics calculation
* Product and category-level analysis
* Time-based sales trend analysis
